                TMUX (Prefix: C-a)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  [ Pane ]
  h,j,k,l -> Select Pane      x       -> Kill Pane
  z       -> Zoom Pane        !       -> Break Pane
  { , }   -> Swap Pane L/R

  [ Session & Windows ]
  s       -> Session List     c       -> New Window
  d       -> Detach Session   ,       -> Rename Window
  n , p   -> Next/Prev Window

  [ Quick Tools ]
  y       -> Yazi             m       -> Spotify
  i       -> Tmux-cht         f       -> Tmux-sessionizer
  D       -> Todo List        r       -> Reload Config 
  
  [ Copy mode ]
  v       -> Copy Mode (Vi)

                NVIM 1: NAVIGATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  [ Harpoon ]
  <leader>a -> 현재 파일을 하푼 리스트에 추가
  <C-e>     -> 하푼 메뉴 열기/닫기
  <C-j>     -> 하푼 리스트 1번 파일로 점프
  <C-k>     -> 하푼 리스트 2번 파일로 점프
  <C-l>     -> 하푼 리스트 3번 파일로 점프
  <C-;>     -> 하푼 리스트 4번 파일로 점프

  [ File System & History ]
  -         -> Oil.nvim 실행
  <leader>u -> Undotree 실행 (시각화된 히스토리)

  [ Window Focus ]
  <A-w>     -> 다음 윈도우(창)로 포커스 이동
  <A-S-w>   -> 이전 윈도우(창)로 포커스 이동

                NVIM 2: SEARCH & LSP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  [ Telescope ]
  <leader>ff -> 프로젝트 내 파일 검색 (이름 기준)
  <leader>fg -> 프로젝트 내 전역 텍스트 검색
  <leader>fb -> 열려 있는 버퍼 목록 탐색
  <leader>fh -> Neovim 도움말 항목 검색

  [ LSP & Intelligence ]
  gd         -> 정의(Definition) 지점으로 이동
  gt         -> 타입 정의 지점으로 이동
  K          -> 커서 아래 심볼 정보 표시 (Hover)
  ]d         -> 다음 진단 지점(에러)으로 이동
  [d         -> 이전 진단 지점(에러)으로 이동
  <leader>vca-> 코드 액션 호출 (Quick Fix)
  <leader>vrn-> 프로젝트 내 심볼 이름 일괄 변경 (Rename)
  <C-h>      -> 함수 시그니처 가이드 호출

  [ Completion (nvim-cmp) ]
  Tab        -> 다음 항목 선택
  S-Tab      -> 이전 항목 선택
  Enter      -> 선택 항목 확정
  <C-Space>  -> 자동완성 수동 호출
  <C-e>      -> 자동완성 창 닫기
  <C-f / b>  -> 상세 문서창 스크롤 (앞/뒤)

                NVIM 3: TROUBLE & GIT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  [ Trouble (Diagnostics) ]
  <leader>xx -> 프로젝트 전체 진단 목록 열기/닫기
  <leader>xb -> 현재 버퍼의 진단 목록만 필터링
  <leader>xs -> 현재 파일 구조(함수/변수) 트리 보기
  <leader>xr -> LSP 참조 및 정의 목록 보기
  <leader>xl -> Location List 호출
  <leader>xq -> Quickfix List 호출

  [ Fugitive (Git) ]
  <leader>gs -> Git 상태창 호출 (메인 메뉴)
  s          -> 파일 스테이징 (Status 창 내부)
  u          -> 스테이징 해제 (Status 창 내부)
  =          -> 변경 사항(Diff) 인라인 표시 토글
  dv         -> 세로 분할 창으로 Diff 보기
  cc         -> 커밋 메시지 작성
  gp         -> 푸시(Push) 실행
  :G write   -> 현재 파일 스테이징 (git add)
  :G read    -> 현재 파일 마지막 커밋 상태로 되돌림
  :G push    -> 원격 저장소 전송
  :G pull --rebase -> 리베이스 기반 업데이트

                NVIM 4: DEBUG & EDITING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  [ Surround & Comments ]
  gcc        -> 현재 행 주석 처리/해제
  gc         -> 선택 영역 주석 처리/해제
  ds"        -> 따옴표(") 감싸기 삭제
  cs"'       -> 따옴표(")를 홑따옴표(')로 변경
  ysiw)      -> 단어를 괄호( )로 감싸기
  yss"       -> 현재 행 전체를 따옴표(")로 감싸기

  [ Debugger (nvim-dap) ]
  <leader>db -> Breakpoint 토글 (중단점 설정/해제)
  <leader>dc -> Continue (디버깅 시작/다음 지점 점프)
  <leader>dn -> Next Line (Step Over)
  <leader>di -> Into Function (Step Into)
  <leader>do -> Out of Function (Step Out)
  <leader>dt -> Terminate (디버깅 완전 종료)
  <leader>dv -> Debug View 토글 (변수/콜스택 창)

  [ Formatting (conform.nvim) ]
  <leader>f  -> 현재 버퍼 코드 스타일 자동 정렬
